# 著者が実行した履歴

ここにあるJSONは、2026年10月18日に著者が実際に実行した結果をマスクした記録です。
これらが存在することは、読者の環境で検証が成功したことを意味しません。

- `entra`：実際のEntraトークンと、ローカルの認可判定。
- `keycloak`：実際のKeycloak受信と、Entraを入力にした自作broker・MCP通信。

読者が実行した結果は `entra/reports` と `keycloak/results` に生成されます。
これらの出力先はGitで無視しています。履歴をコピーして検証を成功したように見せないでください。
Entraのローカル整合性確認には、同じ実行者が保持する保護済みの非公開状態が必要です。
ここには、その状態、認証情報、実際のJWTを含めていません。
